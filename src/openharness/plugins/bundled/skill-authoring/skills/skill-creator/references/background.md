# 分层职责

正文让一次阅读可以理解触发条件、主流程、关键决策与完成标准。
不把大型规范、背景知识和案例复制进正文。

`references/` 保存规范、背景和典型案例。`scripts/` 保存重复使用、结果确定的校验与转换。
`templates/` 定义报告、代码或表格的输出结构；模板资源不注册为技能。

在正文的相关步骤直接引用资源，说明何时使用。按需读取，避免多层跳转和重复维护。
空的脚本目录仅保留占位，不生成无实际用途的可执行程序。
实现业务时，将专属函数、数据模型与报告组织写在各技能自己的 `scripts/`，按职责直接引用。
公共解析、单位转换和通用文件写入可复用；技能专属逻辑不集中到公共目录，也不以单个运行入口薄包装。
